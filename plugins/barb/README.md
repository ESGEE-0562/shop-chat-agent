# Barb Codex plugin

This package distributes the existing repository skills. Their specialist masters remain `.agents/skills/barb-context/SKILL.md` and `.agents/skills/update-barb/SKILL.md` in `ESGEE-0562/shop-chat-agent`. Do not treat these package copies as new knowledge masters.

Install the repository as the `eltee-barb` marketplace, then install `barb`.

Invocation: `$barb:barb-context` for guidance and drafting, `$barb:update-barb` for knowledge maintenance. The installed skill picker is the authority for displayed names.

This is a skills-only plugin. It reads current canonical sources and requires authorised source access. It does not expose the storefront chat service as an MCP server, establish Shopify access, or authorise deployment.
